# Результаты и версии расчётов

| Папка | Что содержит |
| --- | --- |
| `dissertation/main/` | Проверенная спецификация за 1997–2015 с фиксированными эффектами |
| `dissertation/adjusted/` | Проверка с дополнительными лаговыми контролями |
| `dissertation/short-window/` | Проверка в окне −5…+5 |
| `reproduction/cell-76/` | Повторный запуск конкретного исторического сценария, включая его исходные особенности |
| `original-snapshots/` | Существовавшие локальные CSV до повторного запуска; файлы могли быть созданы разными ячейками |
| `descriptive/` | Повторно построенные описательные SVG-графики по панели 1997–2015; расчёты в `dissertation/describe.py` |

Для каждого нового сценария сохраняются таблицы оценок, поддержки по событийному времени, сводки моделей, графики, `summary.csv` и `metadata.json`. Числа между разными папками не следует смешивать как один набор результатов.

Дальние точки event-study могут использовать меньше когорт; это видно в `*_support.csv`. В GitHub сохраняются векторные SVG-графики; PNG для рабочих просмотров не включаются.
