# Данные и происхождение

Репозиторий содержит выбранные локальные снимки данных исходного исследования. Расчёты используют эти файлы и не требуют скачивания новых значений из API. Версии файлов и их происхождение сохранены в [provenance.json](provenance.json); каждый новый расчёт дополнительно записывает SHA-256 входов в `metadata.json`.

| Файл | Содержание | Происхождение |
| --- | --- | --- |
| `raw/qarot.csv` | QAROT, 1947–2015 | Локальный исходный файл `qarot_data.csv` |
| `processed/qarot_minimal.csv` | Код страны, год, год внедрения квоты, представительство женщин | Локальный подготовленный файл; даты внедрения сверены с raw QAROT |
| `processed/country_panel.csv` | 162 страны, 1990–2022, 28 полей | Авторская сборка международных показателей из исходного проекта |
| `raw/pwt_human_capital.csv` | Широкая таблица показателя `hc` | Локальная выгрузка Penn World Table; точный выпуск в исходном проекте не зафиксирован |
| `preparation_history.ipynb` | История подготовки основной панели | Исторический ноутбук, включая ручные шаги и старые пути; не является исполняемым конвейером сборки с нуля |

`country_panel.csv` использует `;` как разделитель и `,` как десятичный знак. Остальные CSV используют обычный формат с запятыми. Ключи основной панели и QAROT — уникальная пара «код страны — год».

## Источники

- QAROT: Hughes, Melanie M., Pamela Paxton, Amanda Clayton, and Pär Zetterberg (2017), *Quota Adoption and Reform over Time, 1947–2015*. [DOI](https://doi.org/10.3886/E100918V1), [страница автора](https://www.amandaclayton.org/data.html).
- Социальные и демографические показатели: [World Development Indicators](https://databank.worldbank.org/source/world-development-indicators).
- Качество институтов: [Worldwide Governance Indicators](https://www.worldbank.org/en/publication/worldwide-governance-indicators).
- Макроэкономическая выгрузка исходного проекта: [IMF World Economic Outlook](https://www.imf.org/en/Publications/WEO/weo-database).
- Показатель `hc`: [Penn World Table](https://www.rug.nl/ggdc/productivity/pwt/).
- Точное происхождение отдельных дополнительных гендерных переменных и даты всех первичных выгрузок восстановлены не полностью. Для основного расчёта используются зафиксированные подготовленные данные, без заявления о воспроизводимости всей цепочки от внешних источников.

Условия использования исходных данных определяются их поставщиками. Авторская сборка и обработка не заменяют ссылки на эти источники.

## Определения, важные для интерпретации

| Поле | Определение по исходному коду и файлам |
| --- | --- |
| `PARL` | Доля женщин в национальном парламенте, проценты; основная панель с заполнением пропусков из QAROT |
| `treat_year` | Первый год `first.implement.flag == 1` в raw QAROT; рассчитывается для страны целиком |
| `Human_Capital` | Индекс `hc` Penn World Table; не HCI Всемирного банка |
| `GDP` | Доля страны в мировом ВВП по ППС; исходный код выбирает показатель `Gross domestic product based on purchasing-power-parity (PPP) share of world total`. Не ВВП на душу населения |
| `Fertility` | Подростковая рождаемость: рождений на 1 000 женщин 15–19 лет. Не суммарный коэффициент рождаемости |
| `Life_Expectancy` | Ожидаемая продолжительность жизни при рождении, годы |
| `Female_Adult_Literacy` | Грамотность взрослых женщин; покрытие разреженное |
| `Corruption` | Оценка контроля коррупции; рост показателя означает улучшение контроля |

Год внедрения квоты не присваивается через объединение по стране и году: иначе он мог бы исчезать за пределами наблюдаемых лет QAROT. Основная оценка заканчивается в 2015 году; отсутствие данных о новых квотах после этого года не трактуется как отсутствие реформ.
